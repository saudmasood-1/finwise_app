# FinWise – Personal Finance Management App

FinWise is a Flutter-based personal finance application designed to help users manage their finances, track expenses, monitor income, and analyze spending.

## Features
- User Authentication with Firebase
- Home Dashboard
- Income and Expense Tracking
- Financial Analysis
- Firebase Cloud Firestore Integration
- Online Support
- User Settings and Profile Management

## Tech Stack
- **Frontend:** Flutter & Dart
- **State Management:** BLoC
- **Backend:** Firebase
- **Database:** Cloud Firestore
- **Authentication:** Firebase Auth
- **Architecture:** Clean Architecture

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/SaudMasood/finwise-app.git
   ```
2. Navigate to the project:
   ```bash
   cd finwise-app
   ```
3. Install dependencies:
   ```bash
   flutter pub get
   ```
4. Run the application:
   ```bash
   flutter run
   ```
